# Cats vs Dogs Image Classification using SVM

## Overview
This project is part of the SkillCraft Technology Machine Learning Internship (Task 03). The goal is to classify images of cats and dogs using a Support Vector Machine (SVM) classifier.

## Dataset
Images of cats and dogs were used and preprocessed by resizing and converting them into numerical feature vectors.

## Workflow
- Data Collection
- Image Preprocessing
- Feature Extraction
- Train-Test Split
- SVM Model Training
- Model Evaluation

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Model
Support Vector Machine (Linear Kernel)

## Results
The model achieved reasonable accuracy in distinguishing between cat and dog images.

## Conclusion
This project demonstrates a basic image classification pipeline using machine learning techniques.
